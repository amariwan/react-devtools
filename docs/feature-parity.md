# React/Next.js DevTools Feature Parity

Date: 2026-10-28

This matrix describes the current worktree, not the aspirational product
blueprint. `PASS` means the behavior has source and runtime evidence in this
repository. `PARTIAL` means only a bounded subset is implemented. `MISSING`
means no implementation was found. `UNVERIFIED` means the contract exists but
the required runtime evidence is not available.

## Reference boundaries

- [React DevTools architecture](https://github.com/facebook/react/blob/main/packages/react-devtools/OVERVIEW.md)
  documents the backend/frontend bridge and lazy detail transfer.
- [React Profiler](https://react.dev/reference/react/Profiler) provides
  supported commit timing callbacks, but does not by itself provide a complete
  DevTools profiler backend.
- [Next.js configuration](https://nextjs.org/docs/app/api-reference/config/next-config-js)
  is loaded by the server/build process and is not a browser integration point.
- [Next.js instrumentation](https://nextjs.org/docs/app/guides/instrumentation)
  distinguishes server instrumentation from early client instrumentation.
- [Vue DevTools](https://github.com/vuejs/devtools) is a behavioral and UX
  reference only; this project has no Vue runtime dependency.
