# CLI

`@next-devtools/cli` provides safe project setup helpers. It is currently a
workspace package; publishing it is separate from the public runtime package.

```bash
next-devtools doctor
next-devtools init
next-devtools init --write
next-devtools remove
```

`doctor` checks the project manifest, Next.js dependency, App Router, config,
DevTools integration, and public package declaration. `init` previews a
minimal `next.config.mjs` by default and creates it only with `--write` when no
Next.js config exists. It never rewrites an existing config. `remove` only
deletes the exact config content generated by `init --write`; user-owned
configuration is left untouched.
